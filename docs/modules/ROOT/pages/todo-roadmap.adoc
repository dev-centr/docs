= Todo & Roadmap
:navtitle: Todo & Roadmap
:description: Org-wide themes, priorities, and development roadmap across Dev-Centr projects.

This page is the **central** Todo & Roadmap for the Dev-Centr org. It summarizes themes and priorities across repositories. For the full, task-level list (including app-specific items), see the link:https://docs.devcentr.org/DevCentr/latest/todo-roadmap.html[DevCentr Todo & Roadmap] in the app documentation.

== Roadmap themes

* **Secrets & SSH** — Standalone secrets manager, back-end providers (e.g. Bitwarden), SSH Manager as coordinator, WSL and venv support. See the DevCentr Secrets Manager docs.
* **Environment navigator** — Model environment hierarchy (Hardware → Hypervisor/OS → VM → Container/App), environment browser, PATH and env var editing.
* **UI** — DPI-aware / logical pixel support for consistent sizing across high-density displays.
* **Installation & packaging** — Installer maker integration (Inno Setup, NSIS), MSI generator, cross-repo release workflow.
* **code-lens (IDE)** — Pedagogical lens switching in editors via link:https://github.com/AMDphreak/code-lens[code-lens]: VS Code webview + AI-generated variants; Zed via LSP/inlays. Feasibility: link:https://github.com/AMDphreak/code-lens/blob/main/docs/editor-integrations.md[editor integrations doc].
* **AI studio tooling** — Prefer marketplace/MCP install ladders when shipping connectors into Cursor-like studios; see xref:general-knowledge::explanation/infrastructure/studio-mcp-install-strategies.adoc[Studio MCP install strategies] and the xref:general-knowledge::reference/ai-studio-tooling-catalog.adoc[AI studio tooling catalog].
* **Fonts / Appearance** — DevCentr can pick and install five OS coding fonts for *this app*. Project Fontsource lock and a Suitcase-style manager are later / separate products -- recorded, not forgotten. Public spec: link:https://docs.devcentr.org/devcentr/specifications/components/appearance.html[Appearance (code font)]. Member orientation: team-docs *Font lock*.

== Current priorities (summary)

* Windows testing automation (libvirt, snapshots, QEMU Guest Agent).
* DevCentr app: Project Templates logic, tool detection, pnpm workspace analysis; Secrets Manager and SSH Manager integration.
* Documentation: VM setup tutorial, standalone Secrets Manager app docs.

Detailed checklists live in the link:https://docs.devcentr.org/DevCentr/latest/todo-roadmap.html[DevCentr Todo & Roadmap] and in each repo's root `TODO.adoc` (or equivalent).
