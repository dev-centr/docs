== 2026

=== July

* **resting-lanczos** — Repo transferred to `dev-centr/resting-lanczos`. Live side-by-side comparison on link:https://devcentr.org/resting-lanczos[devcentr.org/resting-lanczos] (browser bilinear vs Lanczos srcset + transform). Tool overview: xref:tools/resting-lanczos.adoc[resting-lanczos].

Cross-linked from general-knowledge Explanation → Architecture.
