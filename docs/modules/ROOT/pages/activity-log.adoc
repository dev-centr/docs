== 2026

=== August

* **Rules Manager** — Compose/watch daemon + tray for agent-rules (`dev-centr/rules-manager`); Antora component on the hub. xref:rules-manager::index.adoc[Rules Manager docs] · xref:tools/rules-manager.adoc[portal] · https://docs.devcentr.org/rules-manager/
* **Admonition TIP card** — TIP/NOTE label now sits *inside* the bordered card (table chrome). Prior overlay/fix only cleared the green wash and left the border on the body. Brand CSS updated; upstream Valentus / antora-dark-mode unreleased.
* **Theme toggle timing** — Light↔dark animation was uneven: View Transitions (0.28s) raced Valentus `--adt-transition` paint rules (0.2s). Fixed upstream in antora-dark-mode (`html.adt-theme-vt` + `:active-view-transition`); docs brand overlay uses the CSS-only suppress until rolling `v2` updates.
* **Admonition dark TIP wash** — Earlier fix cleared type-tint wash on the TIP label cell (antora-dark-mode 1.4.1 / valentus-theme 2.0.6); superseded by the card-wrap fix above.
* **RepoDrive** — Standalone forge virtual drive (`dev-centr/repo-drive`): GUI + tray, sparse mount, Ibex installers; wired into Antora hub. xref:repo-drive::index.adoc[RepoDrive docs] · xref:tools/repo-drive.adoc[portal] · https://docs.devcentr.org/repo-drive/
* **Switchyard** — New Windows file-association switchyard (`dev-centr/switchyard`): snapshot open/icon tracks, planned icon lock; Antora component on the hub. xref:switchyard:ROOT:index.adoc[Switchyard docs] · xref:tools/switchyard.adoc[portal].
* **valentus-theme head-meta sync** — Restored font-size FOUC + `site-font-size.css` in the supplemental `head-meta.hbs` overlay (was missing after brand fork). Condensed A/A/A control hides on desktop again and scales doc text on mobile. Playbooks already use rolling `v2`.
* **valentus-theme product topic** — This repo (and other Valentus playbooks) tagged with GitHub topic `valentus-theme` for dependency rediscovery; convention documented upstream.
* **DOS naming** — Public category stays Development Orchestration Suite; DevOps framed as one facet of the suite; *Dev OS* as quiet mental model only. Sites + DevCentr vision/capabilities docs updated.
* **Ibex** — Rebrand of Easy Installer (`ibex` CLI): Install Builder EXtension. winget `DevCentr.Ibex`, Homebrew tap, Scoop. xref:ibex:ROOT:index.adoc[Ibex docs] · xref:tools/ibex.adoc[portal].
* **Easy Installer CI emit** — `emit-ci` / `ci-runner.sdl` writes GitHub Actions, GitLab, Azure, Jenkins, CircleCI, and Bitbucket workflows plus `CI-INSTALLER.adoc` without a local package build. DevCentr: `--mode=emit-ci` and New Installer CI pipeline menu. xref:ibex:ROOT:howto-emit-ci.adoc[How-to: emit CI].
* **Easy Installer** — Host for in-place PATH, `installer.kdl` projects, plugin backends (zip/NSIS/Inno/MSI/MSIX/AppImage), and file-manager menus (now **Ibex**). xref:ibex:ROOT:index.adoc[Ibex docs] · xref:tools/ibex.adoc[portal].
* **msi-generator v0.2** — Real OLE2 CFB, uncompressed CAB, and core MSI tables; multi-file MSIX with placeholder assets. xref:msi-generator:ROOT:index.adoc[MSI Generator docs].

Dropped the local `header-content.hbs` override; brand CSS is now accent-token-only. See xref:publishing/antora-ui-branding.adoc[Antora UI branding].

Cross-linked from general-knowledge Explanation → Architecture.
