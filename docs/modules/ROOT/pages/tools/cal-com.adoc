= Cal.com / Cal.diy
:navtitle: Cal.com / Cal.diy
:description: Portal stub for Cal.com hosted scheduling and MIT self-hosted Cal.diy.

Scheduling infrastructure for booking pages, embeds, and later team routing. Prefer hosted **Cal.com** when you want org features and a vendor SLA; use **Cal.diy** when you self-host the MIT community edition.

== Highlights

* Hosted Cal.com for teams / orgs / SSO; Cal.diy for self-host without enterprise modules
* Put public booking hostnames in org `infra` DNS
* Keep calendar OAuth and webhook secrets in the vault
