:navtitle: Mattermost
:description: Portal stub for self-hosted Mattermost as a business support system (chat, integrations, storage).

== Highlights

* Self-host on a VPS (Hetzner/DO/Vultr-class) — not shared/cPanel hosting
* Linear via webhooks or n8n; agents via Composio + Mattermost REST/PATs
* Offload attachments to Cloudflare R2 or Backblaze B2; CDN for hot media
