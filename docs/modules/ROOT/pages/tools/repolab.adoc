= RepoLab
:navtitle: RepoLab
:description: Dev-Centr product — unified browser frontend for git hosts and other VCS backends.

One UI for GitHub, other git hosting APIs, and non-Git version-control engines. RepoLab is a wrapper and cockpit, not a new VCS engine — adapters sit underneath.
