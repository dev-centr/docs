== Highlights

* UI, design systems, tokens, and inspect-friendly handoff
* Open standards (CSS/HTML/SVG/JSON) instead of opaque proprietary files as the only source of truth
* Does not replace motion toolchain choices (SVG / Lottie / Rive)
