= MSI Generator Documentation
:navtitle: MSI Generator
:description: Portal overview for the MSI/MSIX generator.

The MSI/MSIX Generator produces Windows installer packages from a JSON product spec (and CLI flags for simple MSIX cases). It is written in D and runs on Windows, Linux, and macOS while targeting Windows package formats.
