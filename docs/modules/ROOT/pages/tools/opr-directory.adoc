= OPR Directory
:navtitle: OPR Directory
:description: Tentative online Open Provider Registry directory — skeleton only.

**OPR Directory** is a **tentative** hosted catalog where niche providers could self-register and apps could poll.
It is **not** implemented yet. OpenAI-compat does not provide this layer.
