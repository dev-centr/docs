= Easy Installer
:navtitle: Easy Installer
:description: Portal overview for the Easy Installer CLI and shell hooks.

Easy Installer is the cross-platform host for **installer projects** and **Install in-place (add to PATH)**.

* Component docs: xref:easy-installer:ROOT:index.adoc[Easy Installer documentation]
* Repository: link:https://github.com/dev-centr/easy-installer[dev-centr/easy-installer]
* Releases: link:https://github.com/dev-centr/easy-installer/releases[v0.1.0+]
* MSI/MSIX engine: xref:tools/msi-installer-generator.adoc[MSI Generator] / xref:msi-generator:ROOT:index.adoc[component]

== What it is for

* Append a build or tools folder to the user PATH without copying files.
* Scaffold `installer.kdl` and build via plugins (portable zip, NSIS, Inno, MSI/MSIX, AppImage).
* Discover and open optional designer GUIs for backends that have them.
