= Bitwarden / Vaultwarden
:navtitle: Bitwarden / Vaultwarden
:description: Portal stub for Bitwarden cloud, official self-host, and Vaultwarden as vault backends.

Human vault for API keys and org secrets. Same clients (apps, extension, CLI); choose the **server**: Bitwarden cloud, official Bitwarden self-host, or lightweight **Vaultwarden**.

== Highlights

* Cloud Bitwarden is the lean default for most early orgs
* Vaultwarden for tiny self-hosted Bitwarden-compatible API
* Official Bitwarden self-host when SSO / compliance / vendor support matter
* Pair with `bw` CLI custom fields for distribute-to-hosts workflows
