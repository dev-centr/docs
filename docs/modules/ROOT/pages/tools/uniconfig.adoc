= UniConfig Config Panel
:navtitle: UniConfig
:description: Portal overview for ConfigUI — schema-driven editing of config files.

**ConfigUI** (`uniconfig` binary) opens INI, YAML, TOML, SDLang, JSON, and `.tfvars` with shared settings widgets, including fields that are legal but absent.

App developers ship vocabulary in their own repos and register catalogs at runtime — see the component docs.
