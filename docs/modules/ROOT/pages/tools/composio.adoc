= Composio
:navtitle: Composio
:description: Portal stub for Composio—hosted MCP connectors for Gmail, GitHub, Vercel, and other apps.

== Highlights

* Streamable HTTP MCP at `https://connect.composio.dev/mcp`
* Cursor install ladder: marketplace plugin (`/add-plugin`), MCP deeplink, `mcp.json`, local plugin symlink
* Thin plugin (mcp.json + skills) in front of a hosted meta-tool server
* Search-then-execute tool routing (do not invent tool slugs)
* Good fit for **email as CI pager** workflows in Cursor
* Not a replacement for `gh` / local shells—or for Himalaya-based AEI
